# Git Workflow

- Use Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`, `refactor:`) for every commit message.
- Rebase feature branches onto `main` before opening a pull request.
- Never force-push to `main` under any circumstances.
- Keep commit history readable — squash fixup commits before merging.
- Reference the ticket number in the branch name, e.g. `feat/PROJ-123-short-description`.
